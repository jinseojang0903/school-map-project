# 🏫 폐교 지도 시각화

전라남도의 **폐교 121곳**을 지도에 표시하고, 주변 생활 인프라를 점수화해 활용하기 좋은 폐교를 찾을 수 있게 한 웹 서비스입니다.

폐교를 창업 공간이나 귀농·귀촌 거점으로 활용하려는 사람이 "이 폐교 주변에 무엇이 있는지"를 한눈에 비교할 수 있도록 만들었습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 폐교 지도 | 폐교 위치를 마커 클러스터로 표시, 이름으로 검색 |
| 폐교 정보 | 주소, 토지·건물 규모, 금액, 현재 상태 표시 |
| 주변 시설 탐색 | 폐교를 클릭하면 반경 3km 안의 음식점, 편의점, 카페, 병원, 주유소, 숙박시설을 지도에 표시 |
| 고속도로 접근성 | 가장 가까운 고속도로 나들목(IC/JC) 3곳까지의 거리와 주행 경로 표시 |
| TOP 5 순위 | 원하는 시설 항목만 골라 점수를 합산하고 상위 5개 폐교를 다시 계산 |
| 지원 정보 연결 | 청년 지원사업, 귀농·귀촌, 정책 정보 사이트 바로가기 |
| 다크 모드 | 지도와 아이콘이 함께 전환 |

## 입지 점수

폐교마다 주변 시설 수를 집계하고 시설 종류별 점수로 환산했습니다.

| 항목 | 데이터 |
| --- | --- |
| 음식점, 편의점, 카페, 병원, 주유소, 숙박시설 | 카카오 로컬 API로 폐교 주변 시설 수 수집 |
| 고속도로 접근성 | 한국도로공사 고속도로 출입시설 위치 635곳 |

사용자가 중요하게 생각하는 항목만 체크하면, 그 항목의 점수만 합산해 순위를 다시 매깁니다. 예를 들어 병원과 편의점만 선택하면 의료·생활 접근성이 좋은 폐교가 위로 올라옵니다.

## 기술 스택

| 구분 | 기술 |
| --- | --- |
| Backend | Python, Flask |
| 지도 | Folium (Leaflet), MarkerCluster |
| 데이터 처리 | pandas, geopy |
| 외부 API | 카카오 로컬 API (주변 시설 검색), OSRM (주행 경로) |
| Frontend | HTML, JavaScript |

## 프로젝트 구조

```
school-map-project/

├── frontend/

│   ├── script/main.js      # 패널, 체크박스, TOP 5 갱신

├── 데이터/
```

## API

| Method | Endpoint | 설명 |
| --- | --- | --- |
| GET | `/` | 폐교 지도 화면 |
| GET | `/nearby` | 좌표 주변 시설과 가까운 고속도로 나들목 조회 |
| GET | `/route` | 두 지점 사이의 주행 경로 조회 |
| POST | `/api/update_top5` | 선택한 항목으로 TOP 5 재계산 |

## 실행 방법

[Kakao Developers](https://developers.kakao.com/)에서 REST API 키를 발급받아 환경 변수로 설정합니다.

```bash
# macOS / Linux
export KAKAO_API_KEY=발급받은_REST_API_키

# Windows (PowerShell)
$env:KAKAO_API_KEY="발급받은_REST_API_키"
```

```bash
pip install -r requirements.txt
python app.py
```

`http://127.0.0.1:5000`에서 열립니다.
